# Концепты лендинга

Каталог самостоятельных версий лендинга психолога Ольги Сусленниковой.

- `concept-0/v0.1/` — editorial minimalism: светлый природный дизайн, портреты Ольги, авторская SVG-графика, тематически сгруппированные запросы, методы и цены. Состав файлов, контент и локальная проверка описаны в `concept-0/v0.1/README.md`.
- concept-0/v0.2/ — следующая версия с фокусом на ситуации посетителя: сначала запросы, затем системный подход, информация об Ольге и отдельный блок первой консультации. Услуги, цены и форматы работы сохранены; состав файлов и аудит описаны в concept-0/v0.2/README.md.
- Старый стартовый каркас из корня папки удалён. Версии сохраняются в отдельных каталогах и не перезаписывают друг друга.

Новые концепты и версии следует создавать в отдельных каталогах, не перезаписывая существующие варианты.
