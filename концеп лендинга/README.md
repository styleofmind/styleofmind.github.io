# Концепты лендинга

Каталог самостоятельных версий лендинга психолога Ольги Сусленниковой.

- `concept-0/v0.1/` — утверждённая базовая версия: editorial minimalism, светлый природный дизайн, портреты Ольги, авторская SVG-графика, запросы, методы и цены. Состав файлов, контент и локальная проверка описаны в `concept-0/v0.1/README.md`.
- `concept-0/v1.1/` — версия с обновлённым позиционированием: сначала ситуации клиента, затем системный подход и понятный путь к первой консультации. Описание и проверка — в `concept-0/v1.1/README.md`.
- Файлы в корне этой папки сохраняют отдельную стартовую точку прежнего концепта и не используются версией `concept-0/v0.1`.

Новые концепты и версии следует создавать в отдельных каталогах, не перезаписывая существующие варианты.
