# Лендинг Ольги Сусленниковой — концепт 0.1

Самостоятельная статическая версия лендинга в стиле editorial minimalism: тёплый молочный фон, природные шалфейные акценты, выразительная типографика и авторская SVG-графика.

## Состав

- `index.html` — все секции лендинга, SEO-метаданные и структурированный исходный текст.
- `styles.css` — дизайн-система, адаптивные состояния, фокус клавиатуры и reduced motion.
- `script.js` — мобильная навигация и актуальный год в подвале.
- `assets/` — два портрета Ольги, SVG-фоны, системная графика и favicon.

## Контент

Текст и цены предоставлены Ольгой. Список запросов распределён по тематическим группам для удобства чтения; описания услуг и исходные формулировки сохранены там, где это возможно. Не добавлены вымышленные отзывы, контакты или гарантии результата.

## Локальная проверка

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe .\tools\site_tools.py audit --page "концеп лендинга/concept-0/v0.1/index.html"
```

Для ручного просмотра используйте существующий локальный preview-сервер репозитория и откройте путь `концеп лендинга/concept-0/v0.1/`.
