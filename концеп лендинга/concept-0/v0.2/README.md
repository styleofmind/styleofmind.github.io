# Лендинг Ольги Сусленниковой — концепт 1.1

Самостоятельная версия на основе утверждённого v0.1. Визуальная система и фотографии сохранены; изменена смысловая последовательность страницы, чтобы посетитель сначала узнавал свою ситуацию, затем знакомился с системным подходом и видел понятный первый шаг.

## Что изменено в v0.2

- Первый экран: «Не обязательно знать, с чего начать. Давайте разберёмся».
- Блок запросов поставлен перед объяснением системного подхода.
- Заголовок блока запросов обращён к посетителю: «Возможно, вы узнаете себя».
- Добавлен блок первой диагностической консультации: знакомство, обсуждение запроса, план дальнейшей работы.
- Существующие услуги, цены, продолжительность и онлайн/очный формат сохранены.
- Использованы оба исходных портрета Ольги и локальные SVG-ресурсы из v0.1; дополнительные изображения не требуются.

## Состав

- `index.html` — содержание, метаданные и секции страницы.
- `styles.css` — общая дизайн-система и стили блока первой консультации.
- `script.js` — мобильное меню и актуальный год в подвале.
- `assets/` — портреты, авторская SVG-графика и favicon.

## Контент

Исходные формулировки Ольги сохранены по возможности. Изменены заголовок первого экрана и переходные тексты, необходимые для нового позиционирования. Список запросов, описание системного подхода, методы, услуги и цены не удалялись. Не добавлены вымышленные отзывы, квалификации, контакты или гарантии результата.

## Проверка

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe .\tools\site_tools.py audit --page "концеп лендинга/concept-0/v0.2/index.html"
```

Последний запуск аудита: desktop 1440 px, tablet 768 px, mobile 390 px, small mobile 320 px; на всех четырёх размерах `broken_anchors=0`, `broken_images=0`, ошибок консоли и страницы — 0, failed requests — 0. `node --check script.js` завершился с кодом 0. Количество пунктов в блоке запросов сохранено: 30 в v0.1 и 30 в v0.2.

Для локального предпросмотра откройте `концеп лендинга/concept-0/v0.2/` через preview-сервер проекта.
