# UTM-разметка внешних источников

## Правило

UTM-метки ставятся на ссылку, которая ведёт **на сайт** из внешнего канала. Их нужно использовать в описании профиля, закреплённых публикациях и рекламных объявлениях.

Не добавлять UTM к исходящим со страницы сайта ссылкам на MAX, Telegram и WhatsApp: эти переходы ведут с сайта, а не на сайт. Для них уже используются отдельные события аналитики.

Параметры:
- `utm_source` — источник: `telegram`, `max`, `whatsapp`.
- `utm_medium=social` — единая категория для сравнения социальных каналов.
- `utm_campaign` — кампания: `profile` для постоянной ссылки в профиле; отдельный короткий идентификатор для каждой рекламной/контентной кампании.
- `utm_content` — место размещения: `bio`, `pinned_post`, либо идентификатор конкретного объявления.

## Публикации и реклама

Для публикаций сохранять источник и канал, менять кампанию и место:
`?utm_source=telegram&utm_medium=social&utm_campaign=posts&utm_content=post_YYYYMMDD_topic`

Для платной рекламы использовать отдельный medium и отдельное имя кампании, например:
`?utm_source=telegram&utm_medium=paid_social&utm_campaign=campaign_name&utm_content=ad_01`

Имена — латиницей, нижний регистр, без пробелов; слова разделять дефисом или подчёркиванием. Не переиспользовать одно имя кампании для разных рекламных запусков.

## Учёт аналитики

- Яндекс Метрика на сайте: счётчик `113093974`. Источник/кампания будут доступны в отчётах по UTM при условии согласия посетителя на аналитику.
- В текущем production-коде подключена Яндекс Метрика. Google Analytics 4 в `index.html` и `js/analytics*.js` не подключена; отдельное наличие Measurement ID не означает, что сайт отправляет туда данные.
- UTM-разметка не подтверждает заявку или переписку. Для кликов по кнопкам связи используются отдельные события сайта.
- Не добавлять UTM к canonical URL, внутренней навигации, sitemap или SEO-разметке.
