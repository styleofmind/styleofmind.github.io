# Project Context

## Назначение проекта
Style of Mind — сайт психолога, который занимается системными расстановками. Проект предназначен для знакомства посетителей со специалистом и его подходом, объяснения форматов работы и условий, а также для упрощения связи и записи.

В репозитории хранятся несколько концепций и версий сайта для сравнения вариантов подачи. «Концеп расстановки» и «концеп лендинга» — части одного проекта, а не интерьерный дизайн и не отдельный бизнес.

При изменении сайта не выдумывать сведения о психологе, квалификации, опыте, услугах, стоимости, отзывах или результатах работы. Учитывать чувствительность психологической тематики: избегать давления, гарантий результата и неподтверждённых утверждений.

## Репозиторий и публикация
- Репозиторий: `styleofmind/styleofmind.github.io`.
- Основная ветка: `main`; публикация выполняется через GitHub Pages.
- Главная — каталог концептов: `index.html`.
- Каталог разделён на направления «Расстановки» и «Лендинг»; у 10 исходных версий есть отдельная кнопка просмотра скриншотов ПК/планшет/телефон; для новой v1.3 скриншоты ещё не подготовлены.
- `development/catalog-screenshots/` содержит 30 оптимизированных WebP-снимков; локальные PNG-оригиналы хранятся в игнорируемой Git папке `Скрины сайта/`.
- `robots.txt` и `sitemap.xml` находятся в корне. Sitemap намеренно содержит только `https://styleofmind.github.io/`, canonical URL каталога.
- `404.html` показывает страницу «Не найдена» и не перенаправляет автоматически.

## Правила дальнейших изменений
- Перед коммитом: `git status`, `git diff --check`, аудит ресурсов/JavaScript, соответствующий `CHECK_CONCEPT.ps1` и браузерные проверки.
- Перед подтверждением выпуска проверить публичные URL и GitHub Actions; локальный commit сам по себе не доказывает успешную публикацию.
- Коммитить только проверенные файлы; не выполнять force push/reset.
- Избегать широкого редизайна без запроса; исправлять реальные дефекты точечно.

## Документация для ИИ-агентов

- `README.md` — точка входа, назначение сайта и правила работы ИИ.
- `AI_DOCS/ARCHITECTURE.md` — архитектура статического сайта и карта целевой страницы.
- `AI_DOCS/OPERATIONS.md` — порядок внесения изменений, проверки и публикации.

При работе над проектом начинать с `README.md`, затем читать профильные документы. Подробные процедуры локального запуска и аудита остаются в `guides/LOCAL_PREVIEW.md` и `guides/AUDIT_TOOLING.md`.

- All HTML pages in `development/` include `<meta name="robots" content="noindex,nofollow">`. `sitemap.xml` excludes the development directory. `robots.txt` permits crawling so search engines can read the noindex directive.

## SEO и метаданные production
- `robots.txt` разрешает обход сайта и указывает на корневой `sitemap.xml`.
- `sitemap.xml` содержит canonical URL главной страницы; каталог `development/` в карту не включать.
- Корневой `index.html` содержит `title`, `meta description`, canonical, Open Graph/Twitter metadata и JSON-LD (`Person` + `WebSite`). Для превью используется `assets/og/olga-social-preview.webp` — WebP-версия изображения портрета с тёплым светлым фоном. Предыдущий исходный портрет сохранён отдельно как `assets/og/1_olga-social-preview.webp`.
- `site.webmanifest` описывает название сайта и использует статический `favicon.svg`; анимированный `favicon-loading.svg` остаётся favicon в HTML.
- Не добавлять в структурированные данные адрес, отзывы, рейтинги или неподтверждённые квалификации.

## Analytics scope
- Analytics scripts are loaded only on the root production homepage after explicit visitor consent. Development concept pages and privacy-policy.html do not load tracking providers.
