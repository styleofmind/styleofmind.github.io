# План — дальнейшая работа с сайтом

## Текущий статус

Работу над `concepts/concept-0/v0.2` временно останавливаем. Текущая версия сохранена в репозитории.

## Отложено

### 1. Проверить доступность GitHub Pages
- Проверить, открывается ли `/concepts/concept-0/v0.2/` после последних коммитов.
- Проверить статус и результат последнего GitHub Pages deployment.
- Если страница недоступна, сначала разобраться с публикацией, а не менять сам сайт.
- Учесть, что после push GitHub Pages может потребоваться время на публикацию; GitHub рекомендует смотреть workflow/deployment status при проблемах. 

### 2. Оптимизировать оставшиеся WebP
- Не менять изображения вслепую.
- В первую очередь проверить самые тяжёлые используемые файлы сертификатов и фотографий.
- Сохранить исходные размеры и читаемость текста на сертификатах.
- Сравнить размер и визуальное качество до/после.
- Заменять только те файлы, где выигрыш действительно заметен.

### 3. Финальный визуальный QA
После восстановления доступности:
- пройти весь scroll от hero до footer;
- отдельно проверить мобильную версию;
- проверить карусели, галереи, FAQ, cookie-настройки и CTA;
- проверить отсутствие горизонтального overflow;
- проверить reduced-motion и keyboard focus;
- проверить ссылки, sitemap и robots.txt.

### 4. Не переделывать дизайн без необходимости
Текущее направление оставить:
- спокойная визуальная система;
- меньше декоративных эффектов;
- акцент на Ольге, человеке и содержании;
- Lora + Lato;
- песочный фон, зелёный и золото как акценты.

Следующий этап — не новая концепция, а точечная доводка после проверки реального опубликованного сайта.
