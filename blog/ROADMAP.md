# Roadmap блога

Внутренний план развития блога. Это список задач проекта, а не публичное обещание дат выхода материалов.

## 1. Подготовить основу

- [ ] Определить тематические направления и рубрики блога.
- [ ] Составить редакционный план тем; постепенно собрать резерв черновиков (ориентир — до 500 тем/материалов, без требования публиковать их все).
- [ ] Подготовить единый шаблон статьи: заголовок, описание, дата публикации, текст, иллюстрации, ссылки.
- [ ] Зафиксировать правила качества: самостоятельная польза, точность формулировок, отсутствие повторов и искусственного SEO-текста.
- [ ] Подготовить структуру хранения черновиков отдельно от опубликованных статей.

## 2. Реализовать отложенную публикацию

- [ ] Добавить дату публикации и статус материала: черновик / запланирован / опубликован.
- [ ] Реализовать вывод только тех статей, дата публикации которых наступила.
- [ ] Сформировать список статей блога автоматически из опубликованных материалов.
- [ ] Исключить черновики и будущие публикации из sitemap.xml, внутренних ссылок и публичных страниц.
- [ ] Проверить, что будущую статью нельзя открыть по прямому URL до даты публикации.

## 3. Настроить постепенный выпуск

- [ ] Начать с одной содержательной статьи раз в 1–2 недели.
- [ ] Проверять качество и реакцию на опубликованные материалы перед увеличением частоты.
- [ ] Не выпускать статьи только ради соблюдения графика.
- [ ] Поддерживать запас проверенных материалов, не превращая ориентир по количеству черновиков в обязательный план публикаций.

## 4. SEO для каждой публикации

- [ ] Подготовить уникальные title и description.
- [ ] Добавить canonical, Open Graph и корректную разметку Article или BlogPosting.
- [ ] Добавить внутренние ссылки на релевантные страницы сайта и другие статьи.
- [ ] Включать URL в sitemap.xml только после публикации.
- [ ] Проверить мобильную версию, изображения, доступность и корректность ссылок.
- [ ] После появления первых полноценных публикаций убрать noindex со страницы блога и проверить индексацию.

## 5. Поддержка и развитие

- [ ] Периодически проверять битые ссылки, отображение и актуальность материалов.
- [ ] Обновлять статьи, если меняются сведения или формулировки.
- [ ] Анализировать поисковые запросы и статистику, чтобы планировать следующие темы.
- [ ] Пересматривать частоту публикаций по результатам, а не по формальному графику.

- [ ] Подготовлен и опубликован первый материал.
