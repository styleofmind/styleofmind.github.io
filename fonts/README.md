# Локальные шрифты

Все веб-шрифты проекта находятся в корневой папке fonts/. Общие определения лежат в fonts/fonts.css, а все пути в нём относительные к этой папке. Страницы подключают таблицу стилей по адресу /fonts/fonts.css. Это работает на GitHub Pages и при локальном HTTP-просмотре проекта.

## Семейства

- Cormorant Garamond — кириллица и латиница, начертания 400–600.
- Manrope — кириллица и латиница, начертания 400–700.
- Inter — кириллица и латиница, начертания 400–600.
- Lato — латинский набор, обычное и жирное начертание. В исходном комплекте нет кириллического поднабора Lato, поэтому для русских символов используется резервный шрифт из стека.
- Lora — кириллица и латиница, начертания 400–700.
- Montserrat — кириллица, расширенная кириллица, латиница и расширенная латиница, начертания 400–700.
- Playfair Display — кириллица, латиница и расширенная латиница, начертания 400–600.

## Лицензии

Лицензии SIL Open Font License для семейств сохранены рядом с файлами шрифтов в файлах OFL-*.txt. Все веб-шрифты загружаются с текущего сайта; внешние сервисы шрифтов не требуются.

Системные стеки Arial, Georgia, Segoe UI и другие резервные варианты остаются системными — их нельзя переносить как веб-шрифты без изменения дизайна.
