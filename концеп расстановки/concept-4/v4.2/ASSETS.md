# Карта ресурсов — Концепт 4.2

В репозитории находятся ресурсы, которые использует страница, а также небольшой согласованный визуальный эталон.

## Используемые ресурсы

| Каталог | Содержимое и назначение |
|---|---|
| assets/backgrounds/ | section-01.jpg–section-12.jpg, section-08-composed.jpg, section-11-composed.jpg и about-watercolor-background.jpg |
| assets/identity/ | brand-mark.svg |
| assets/fonts/ | Локальные файлы шрифтов Montserrat и Playfair Display в WOFF2 и соответствующие тексты лицензий OFL |
| assets/portraits/ | PNG-оригиналы портретов; адаптивные WebP-варианты для загрузки с PNG-fallback |
| assets/scenes/ | about-arch-interior.png — графический фон блока «Обо мне» |
| assets/why-me/ | Текстура, ботанический элемент, рамка и золотые декоративные детали |
| assets/references/ | style-guide-olga-suslennikova.png — визуальный эталон |

Все изображения, на которые ссылаются HTML и CSS, проверяются локальным скриптом CHECK_CONCEPT.ps1. Двенадцать основных фоновых изображений сохранены в JPEG; для блоков 8 и 11 предусмотрены дополнительные собранные композиции.

## Локальные материалы, не включаемые в Git

Каталог assets/страница листы/ содержит исходные референсы, монтажные листы, кадры и альтернативные варианты дизайна. Это локальный архив исходных материалов, который не используется опубликованной страницей. Предпросмотры из previews/, отчёты site-audit/ и снимки из «Скрины сайта» также остаются локальными рабочими материалами.

## Правило обновления

В Git добавлять только ресурсы, используемые HTML/CSS/JavaScript, и небольшой набор согласованных справочных документов. Перед заменой или удалением файла проверить ссылки и запустить CHECK_CONCEPT.ps1 и браузерный аудит.
