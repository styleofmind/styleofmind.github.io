# Project Context

## Репозиторий и публикация
- Репозиторий: `styleofmind/styleofmind.github.io`.
- Основная ветка: `main`; публикация выполняется через GitHub Pages.
- Главная — каталог концептов: `index.html`.
- Каталог разделён на направления «Расстановки» и «Лендинг»; у каждой из 10 версий есть отдельная кнопка просмотра скриншотов ПК/планшет/телефон.
- `catalog-screenshots/` содержит 30 оптимизированных WebP-снимков; локальные PNG-оригиналы хранятся в игнорируемой Git папке `Скрины сайта/`.
- `robots.txt` и `sitemap.xml` находятся в корне. Sitemap намеренно содержит только `https://styleofmind.github.io/`, canonical URL каталога.
- `404.html` показывает страницу «Не найдена» и не перенаправляет автоматически.

## Проверенное состояние
- Все 21 HTML-файл локально проверен Chromium при ширинах 1440, 768, 390 и 320 px; нет горизонтального переполнения, сломанных локальных якорей/изображений и ошибок браузера.
- Статический аудит проверяет 345 локальных ссылок и ресурсов; отсутствующих файлов не найдено.
- `node --check` проходит для всех 16 отслеживаемых JS-файлов; синтаксис трёх inline-скриптов также корректен.
- Интерактивные тесты: cookie consent (принятие/отказ), галерея сертификатов, FAQ, мобильное меню и просмотрщик скриншотов проходят.
- `CHECK_CONCEPT.ps1` для v4.1 и v4.2 проходит; CSS сбалансирован, изображения и стили на месте.
- Повторное WebP-сжатие крупных сертификатов не дало экономии; для одной фотографии выигрыш составил около 9%. Оригиналы оставлены, чтобы не ухудшать читаемость текста и деталей.

## Правила дальнейших изменений
- Перед коммитом: `git status`, `git diff --check`, аудит ресурсов/JavaScript, соответствующий `CHECK_CONCEPT.ps1` и браузерные проверки.
- Перед подтверждением выпуска проверить публичные URL и GitHub Actions; локальный commit сам по себе не доказывает успешную публикацию.
- Коммитить только проверенные файлы; не выполнять force push/reset.
- Избегать широкого редизайна без запроса; исправлять реальные дефекты точечно.

## Документация для ИИ-агентов

- `AI_DOCS/README.md` — точка входа и правила работы ИИ.
- `AI_DOCS/ARCHITECTURE.md` — архитектура статического сайта и карта целевой страницы.

При работе над проектом начинать с `AI_DOCS/README.md`, затем читать профильные документы. Подробные процедуры локального запуска и аудита остаются в `LOCAL_PREVIEW.md` и `AUDIT_TOOLING.md`.
